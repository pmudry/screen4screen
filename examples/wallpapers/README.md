# Example layout

Drop images here to try the script against this folder:

```powershell
.\Set-WallpaperByResolution.ps1 -Once -Verbose -WallpaperRoot .\examples\wallpapers
```

Suggested files for a laptop + ultrawide + meeting-room setup:

```
examples/wallpapers/
  1920x1200.jpg      laptop panel
  5120x2160.jpg      ultrawide at the desk
  ratio-16x9.jpg     any 1080p / 1440p / 4K external
  default.jpg        anything else
```

Images in this folder are git-ignored except this README.
